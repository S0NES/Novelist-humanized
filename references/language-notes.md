# Language notes

The patterns in `SKILL.md` exist in every language. These are the common forms in a few languages. For any other language, find the equivalent construction and treat it the same way.

## Dialogue punctuation

The default is straight double quotes ("...") in every language, because dialogue dashes count as dashes under rule 8. If the author's own sample uses the traditional form (the Portuguese or Spanish dash, Chinese corner quotes 「」 or curly quotes “”), follow the sample consistently.

## Portuguese (Brazil)

| Rule | Watch for |
|---|---|
| 1 Not X but Y | "Não era medo, era cálculo." "Não é só uma arma, é uma promessa." "..., sem hesitar." |
| 2 Closers | "Aquilo mudava tudo." "E ela sabia." "Nada de medo. Nada de dúvida." |
| 3 Deep sayings | "No fundo", "a verdadeira questão", "o preço da liberdade" |
| 4 Run-ups | "A verdade é que", "Sinceramente?", "Olha," as an opener |
| 5 Arguing with no one | "Não que ele tivesse medo." "Não era sobre dinheiro." |
| 11 Banned words | crucial, intricado, meticuloso, vibrante, tapeçaria, testemunho de, mergulhar fundo, ressaltar, fomentar, robusto (figurative), silenciosamente (mood), "um misto de", "uma dança de" |
| 12 Inflation | "um momento que mudaria tudo", "uma marca indelével", "o início de uma nova era" |
| 13 Gerund tails | ", simbolizando sua liberdade", ", refletindo anos de dor" |
| 14 Sales language | "aninhada", "de tirar o fôlego", "no coração da cidade" |
| 15 Plain verbs | "serve como", "se ergue como", "ostenta" become "é", "tem", "fica" |
| 17 Stock idioms | "coração disparado", "o sangue gelou", "silêncio ensurdecedor", "o tempo parou", "lágrimas rolaram" |
| Dialogue | "Você é cruel." "Não sou cruel, sou preciso." |

## Chinese

| Rule | Watch for |
|---|---|
| 1 | 不是……而是……; 这不仅仅是……更是…… |
| 2 | 一切都变了。她知道。 as a standalone closing line |
| 3 | 归根结底, 真正的问题是 |
| 11 | Piles of ornate adjectives: 璀璨, 瑰丽, 绚烂 |
| 16 | Abstract emotion: 心中涌起复杂的情感 becomes a concrete action or line |
| 17 | Stacked four-character set phrases: 心潮澎湃, 热血沸腾 |

Chinese chapters are measured in characters, not words. `scripts/wordcount.py` counts CJK characters automatically when they are the majority.
